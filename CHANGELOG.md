# Changelog

All notable changes to WilyCode Database Model are documented here.

## [Unreleased]

### Changed

- Updated related-package links to the renamed database packages.

## [0.1.0] - 2026-10-13

### Added

- Initial public release of validated, attribute-based model metadata.
- Model hydration from database rows, JSON object/array data, and nested relation payloads.
- HasOne, HasMany, and HasManyToMany relationship definitions and load states.
- Foreign-key reference objects, array conversion, backed enum support, and scalar casting.
- Original-value snapshots and insert/update change tracking.
- English documentation, PHPUnit tests, and GitHub Actions.
